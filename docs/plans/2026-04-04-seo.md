# SEO Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add comprehensive SEO to the ESTRID band website — metadata, Open Graph, structured data, sitemap, robots.txt, and favicon.

**Architecture:** Single-page static export (Next.js 15, GitHub Pages). No server-side rendering, no API routes. All SEO is done via static metadata exports in `app/layout.tsx`, `app/sitemap.ts`, `app/robots.ts`, and JSON-LD in `app/page.tsx`. OG image is a static file (no `next/og` dynamic generation — not supported in `output: 'export'`).

**Tech Stack:** Next.js 15 App Router Metadata API, JSON-LD (MusicGroup schema), static files in `/public`

### Task 3: Add robots.txt

**Files:**
- Create: `app/robots.ts`

**Step 1: Create the file**

```ts
// app/robots.ts
import { MetadataRoute } from "next";

export default function robots(): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: "*",
      allow: "/",
    },
    sitemap: "https://estrid.my/sitemap.xml",
  };
}
```

**Step 2: Verify it generates**

```bash
yarn build && cat out/robots.txt
```

Expected output:

```
Sitemap: https://estrid.my/sitemap.xml
```

### Task 4: Add sitemap.xml

**Files:**
- Create: `app/sitemap.ts`

**Step 1: Create the file**

Since this is a single-page site with anchor sections, the sitemap contains the root URL plus the major section anchors:

```ts
// app/sitemap.ts
import { MetadataRoute } from "next";

export default function sitemap(): MetadataRoute.Sitemap {
  const baseUrl = "https://estrid.my";

  return [
    {
      url: baseUrl,
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 1,
    },
    {
      url: `${baseUrl}/#about`,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 0.8,
    },
    {
      url: `${baseUrl}/#music`,
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 0.9,
    },
    {
      url: `${baseUrl}/#tour`,
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 0.9,
    },
    {
      url: `${baseUrl}/#berita`,
      lastModified: new Date(),
      changeFrequency: "weekly",
      priority: 0.8,
    },
    {
      url: `${baseUrl}/#contact`,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 0.6,
    },
  ];
}
```

**Step 2: Verify**

```bash
yarn build && cat out/sitemap.xml
```

Should output a valid XML sitemap with all URLs.

### Task 5: Add JSON-LD structured data (MusicGroup schema)

**Files:**
- Modify: `app/layout.tsx`

This helps search engines understand ESTRID is a music group — enabling rich results.

**Step 1: Add JSON-LD script tag inside `<body>`**

In `app/layout.tsx`, add a `<script>` tag with JSON-LD before `{children}`:

```tsx
const jsonLd = {
  "@context": "https://schema.org",
  "@type": "MusicGroup",
  name: "ESTRID",
  url: "https://estrid.my",
  description:
    "ESTRID. Muzik, jadual persembahan, galeri, dan berita terkini.",
  genre: ["Rock", "Malaysian Rock"],
  image: "https://estrid.my/images/og-image.jpg",
  sameAs: [
    // Add social media URLs here, e.g.:
    // "https://www.instagram.com/estridband",
    // "https://www.facebook.com/estridband",
    // "https://www.youtube.com/@estridband",
  ],
};
```

Then inside `<body>`, before `{children}`:

```tsx
<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }}
/>
```

**Step 2: Fill in sameAs social URLs**

Replace the comment placeholders with ESTRID's actual social media profile URLs.

**Step 3: Verify**

```bash
yarn build && grep -A 5 "application/ld+json" out/index.html
```

Should show the JSON-LD block in the HTML.

Optionally validate using Google's Rich Results Test: https://search.google.com/test/rich-results

**Step 4: Commit**

```bash
git add app/layout.tsx
git commit -m "seo: add MusicGroup JSON-LD structured data"
```

### Task 6: Add favicon and PWA meta tags

**Files:**
- Create: `public/favicon.ico` (or `app/icon.tsx` / static files)
- Modify: `app/layout.tsx`

**Step 1: Add favicon files**

The simplest approach for static export: place favicon files directly in `/public` and reference them in layout.

Place these files in `/public`:
- `favicon.ico` — 32×32 ICO file
- `apple-touch-icon.png` — 180×180 PNG
- `favicon-192.png` — 192×192 PNG (for PWA)

If you have a logo, export it to these sizes from the `estrid-logo.png`.

**Step 2: Add icons metadata to layout.tsx**

Add to the `metadata` export:

```tsx
icons: {
  icon: "/favicon.ico",
  apple: "/apple-touch-icon.png",
  other: [
    { rel: "icon", url: "/favicon-192.png", sizes: "192x192", type: "image/png" },
  ],
},
```

**Step 3: Add theme color**

Add to `metadata`:

```tsx
themeColor: "#DC2626",
```

**Step 4: Verify**

```bash
yarn build && grep -E "favicon|apple-touch|theme-color" out/index.html
```

**Step 5: Commit**

```bash
git add public/favicon.ico public/apple-touch-icon.png public/favicon-192.png app/layout.tsx
git commit -m "seo: add favicon, apple-touch-icon, and theme color"
```
